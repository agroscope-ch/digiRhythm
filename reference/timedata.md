# timedata Dataset of start and end of day and night

A dataset of start and endtime of the morning milking and evening
milking on a dairy farm.

## Usage

``` r
timedata
```

## Format

A data frame of 4 columns

- day_start:

  a POSIX formatted datetime

- day_end:

  a POSIX formatted datetime

- night_start:

  a POSIX formatted datetime

- night_end:

  a POSIX formatted datetime
